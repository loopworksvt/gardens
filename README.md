# Garden plant reference

A reference for garden plants: what each needs to thrive, its growing season, fall tasks, propagation and dividing, with a photo and sources, as web pages that work on a phone.
Open `index.html` (or the site address), then use your browser's Add to Home Screen; every page and picture is saved on the device after the first visit (each file separately, so an update downloads only what changed), and a line at the foot of each page says how many are saved.

- Built 2026-11-05: 24 pages, 22 pictures, 5 MB.
- General gardening information summarized from public sources (extension services, botanical gardens, the RHS), not professional advice. Each page lists its sources.
- Photographs are public domain or openly licensed (Wikimedia Commons); credits are on each page and in `credits.html`.
- Generated from a private notes vault by `export_garden_reference.py`; it contains the plant notes' public fields plus the location and GPS the owner recorded, and no other notes, logs or records. Do not edit these files by hand: rebuild and replace them.
